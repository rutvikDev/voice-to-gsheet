Google Sheets & Render Setup Guide

Follow these quick steps to connect your live sheet & deploy to Render

1

Open your Google Sheet & Apps Script

Create a new spreadsheet at sheets.new, then click Extensions > Apps Script.

2

Paste the Webhook Code

Copy the code from google-apps-script.js (included in this project) and paste it into the editor.

3

Deploy as Web App

Click Deploy > New deployment. Choose Web app, set Execute as: "Me", and Who has access: "Anyone".

4

Set Environment Variable

Copy the generated Web app URL and set in your .env or Render Environment Variables:

GOOGLE_SHEET_WEBHOOK_URL=https://script.google.com/macros/s/YOUR_URL/exec
1

Google Cloud Console

Enable the Google Sheets API in Google Cloud Console.

2

Create Service Account

Create a service account, download JSON key, and share your Google Sheet with the service account email as Editor.

3

Set Environment Variables

GOOGLE_SHEET_ID=your_sheet_id
GOOGLE_CLIENT_EMAIL=your-sa@project.iam.gserviceaccount.com
GOOGLE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n..."
1

Push to GitHub

git init
git add .
git commit -m "Voice to Google Sheets ready"
git push origin main
2

Create Web Service on Render

On Render, create a New > Web Service and select your GitHub repo.

Build Command: npm install • Start Command: npm start

3

Add Environment Variables on Render

In the Environment tab on Render, add your GOOGLE_SHEET_WEBHOOK_URL or Service Account keys.
